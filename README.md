# BastionStairsWeb

Full source code for my stairs game hosted at [kelvvin.com](https://kelvvin.com/stairs)

## Setup

Clone the repository and install project dependencies:

`npm install`

## Build

This repository already has the game compiled. If you wish to make changes, recompile with:

`npm run build`

This script will bundle `config/gameConfig.ts` and `game.ts` together and build `game.js`

## Formatting

Prettier is included to format the code with a suggested `.prettierrc`

`npm run fmt`

## Play

Open `game.html` in a browser
